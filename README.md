# Java Thread Practice

This project demonstrates how to create and run **threads** in Java.

## Examples

### MyThread
- Extends the `Thread` class
- Overrides the `run()` method
- Shows the difference between `run()` and `start()`

### RunnerRace
- Creates multiple threads
- Assigns names using `setName()`
- Runs threads concurrently with `start()`

## Concepts
- Thread creation
- `run()` vs `start()`
- `Thread.currentThread()`
- Multithreading

## Purpose
- Learn the basics of Java threads
- Understand concurrent execution
- Practice working with multiple threads

## Run
Run `Thread1` and `RunnerRace` separately.
